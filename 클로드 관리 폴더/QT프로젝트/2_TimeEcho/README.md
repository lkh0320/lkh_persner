# TimeEcho — 과거의 나와 협동하기

## 핵심 아이디어 한 줄

> 물리를 **고정 타임스텝 + 정수 연산**으로만 돌리면,
> 틱마다 입력 1바이트만 저장해도 그 회차를 **완벽히 재현**할 수 있다.

유령은 녹화 영상이 아니라 **같은 코드로 다시 시뮬레이션되는 진짜 개체**입니다.
그래서 딛고 올라설 수 있고, 버튼을 누를 수 있습니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `sim.h/.cpp` | **Qt에 전혀 의존하지 않는** 결정론적 시뮬레이션. 부동소수점 0개 |
| `gamewidget.h/.cpp` | 렌더링 + 입력 + 고정 타임스텝 루프 |
| `main.cpp` | 창 하나 띄우기 |

`sim`이 Qt를 모르는 게 핵심입니다. 그래야 재현성을 신뢰할 수 있고, 나중에 테스트도 짤 수 있습니다.

## 결정론을 지키는 3가지 규칙

1. **부동소수점 금지.** 좌표는 `int` 픽셀 + `int` 서브픽셀 누적분(1px = 256)입니다.
   `float`를 쓰면 컴파일러 최적화 옵션만 바뀌어도 재생이 어긋납니다.
2. **물리는 정확히 1/60초씩만 전진.** 렌더링 프레임레이트와 완전히 분리했습니다
   (`gamewidget.cpp`의 누적기 방식). 창을 끌어서 프레임이 밀려도 시뮬레이션은 안 틀어집니다.
3. **개체 처리 순서 고정.** 과거의 나들이 먼저, 지금의 내가 마지막. 항상 같은 순서.

저장 용량은 **틱당 1바이트**입니다. 5분짜리 회차도 18KB밖에 안 됩니다.

## 검증해둔 것

헤드리스로 시뮬레이션만 돌려서 확인했습니다.

- 혼자서는 문 앞(x=384)에서 막힘 — 1인 클리어 불가 ✔
- 유령 1명(문만 열림)으로는 선반에 못 올라감 (최고점 py=349, 필요 py=312) ✔
- 의도한 3회차 순서로는 클리어됨 ✔
- 같은 입력 배열을 3번 재생 → 최종 상태 완전히 동일 ✔ (결정론)

## 알려진 한계 (프로토타입이라 일부러 안 넣은 것)

- 유령 위에 올라탄 상태에서 **유령이 움직여도 같이 실려가지 않습니다.** (이번 퍼즐은 유령이 가만히 서 있어서 문제없음)
- 시작 지점에서 모두 겹쳐서 스폰되므로, "이미 겹쳐 있는 상대에게는 막히지 않는다"는 예외를 두었습니다.
- 레벨이 하나뿐이고 코드 안에 문자열로 박혀 있습니다.
- 유령이 과거에 갔던 길을 지금의 내가 막으면 유령이 어긋납니다(패러독스). 지금 레벨은 동선이 겹치지 않게 설계해서 피했습니다.
