# WindowPuzzle — 창 자체가 레벨인 퍼즐

## 핵심 아이디어 한 줄

> 게임 세계는 **전역 데스크톱 좌표계** 하나뿐이고,
> 각 창은 그 세계를 들여다보는 **구멍**이다.
> 갈 수 있는 공간 = 열려 있는 모든 창 내부 영역의 **합집합**.

그래서 창을 옮기고 늘이는 것이 곧 레벨을 바꾸는 행위가 됩니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `rectutil.h` | `subtractRect` / `fullyCovered` — 사각형 합집합 커버리지 판정. **게임 규칙의 심장** |
| `world.h/.cpp` | 전역 좌표계 위의 물리. 창 목록만 알고 있고 그 합집합 밖으로는 못 나간다 |
| `gamewindow.h/.cpp` | 창 하나. `geometry()`로 자기가 비추는 세계 영역을 알고 그 부분만 렌더링 |
| `main.cpp` | 창 3개 생성 + 앱 전역 키 필터 + 60fps 타이머 |

## 구현에서 유일하게 까다로운 부분

"플레이어의 사각형이 **여러 창의 합집합 안에 완전히 들어가는가**"를 판정하는 것.

`rectutil.h`의 방식은 정확하고 단순합니다.
- `A - B`(사각형 빼기)는 최대 4조각으로 떨어진다
- 플레이어 사각형에서 창들을 차례로 빼 나가서 **아무것도 남지 않으면** 완전히 덮인 것

창이 8~10개 수준이면 비용은 무시해도 됩니다.

이동은 1px씩 밀어보고 막히면 멈추는 방식이라 터널링(빠른 속도로 벽을 뚫는 문제)이 없습니다.

## 알려진 한계 (프로토타입이라 일부러 안 넣은 것)

- 창을 옮길 때 캐릭터가 "밀려나지" 않습니다. 창 밖으로 나가면 허공 상태가 됩니다.
- 멀티 모니터 / 배율(DPI) 혼합 환경은 테스트하지 않았습니다. 창 퍼즐로 가면 여기가 첫 번째 난관입니다.
- 레벨 개념이 없습니다. 목표 지점 하나뿐입니다.
